### Main Topic: Brain Memory Control

**Main Thesis:** Brain stimulation does not increase working memory capacity or control; the limits on memory are based on how the brain can coordinate its own physical parts.

**Simple Summary:** The author argues against the idea that you can expand your working memory by stimulating the brain. They suggest that what we call "control" over memory is simply the result of different parts of the brain working together. Because the brain can only coordinate so many pieces at once, it cannot natively hold more information. To improve memory, we should focus on building external tools and systems rather than trying to expand the brain itself.

**The Bottom Line:** > You cannot naturally increase your working memory capacity by changing brain activity; true cognitive expansion requires building external systems and tools.
