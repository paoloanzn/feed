### Main Topic: Link submission error

**Main Thesis:** Changes to the website's design caused a bug that made it difficult to submit a link correctly.

**Simple Summary:** The writer tried to post a link but failed because the website's layout and forms were changed. They suspect a new, confusing confirmation feature accidentally deleted the link they pasted, which is a common problem when software updates change the way things look.

**The Bottom Line:** > When websites change their design, it often causes errors and confusion for users, making it frustrating to use the system.
