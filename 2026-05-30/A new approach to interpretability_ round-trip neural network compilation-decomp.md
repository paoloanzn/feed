### Main Topic: AI Code Link
**Main Thesis:** A specific process called a "round-trip" proves that the symbolic source code of a program is mathematically identical to the behavior of the neural network it creates, offering a new way to understand computation.

**Simple Summary:** The author developed a new way to program where code compiles into mathematical structures (tensor-op graphs). The core idea is that you can take a trained AI model, extract its learned settings, and use those settings to recreate the original source code exactly. This process proves a direct, verifiable link between the written program and the resulting AI behavior.

**The Bottom Line:** > This round-trip property is a new type of verification that focuses on *how* a program computes, rather than just what its internal parts mean, which could be a useful tool for understanding and improving AI.
