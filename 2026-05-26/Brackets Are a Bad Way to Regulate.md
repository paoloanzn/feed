### Main Topic: Distribution inefficiency

**Main Thesis:** Using fixed brackets to manage continuous data (like speed or tax rates) creates inefficiency and encourages exploitation, whereas using mathematical functions provides a fairer and more efficient system.

**Simple Summary:** Most rules and regulations use "brackets" (like speed limits or tax tiers) to handle continuous measurements. The author argues that this system is inefficient because the treatment of the ends of these brackets is unfair and incentivizes people to exploit the system (e.g., paying for extra time or escalating crimes). The solution is to use mathematical formulas (functions) instead of brackets, as functions can smoothly apply rewards or punishments across any range, eliminating this waste.

**The Bottom Line:** > To create fair and efficient rules, we should replace arbitrary brackets with mathematical formulas that treat continuous changes smoothly, rather than relying on segmented, exploitable thresholds.
